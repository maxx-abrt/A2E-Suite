## What A2E Suite adds

A2E Suite is a modular workspace built on Twenty. Beside the native CRM it adds
work and knowledge (**Bureau**), finance (**Bilan**), the AI assistant
(**Syna**) and file storage (**Archive**), plus a shared **Templates** gallery.
