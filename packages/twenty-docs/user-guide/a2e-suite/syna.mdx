## Scope

Set up a provider with your own key, ask questions in context, and use the
per-app AI actions — with a correct zero-AI state when no key is configured.

## Screens this page will cover

- Settings → **Syna**: tabs `Overview`, `Models`, `Skills`, `Tools`, `Usage`,
  `Audit`; `New Skill`, `New Tool`, `Watch AI demo`.
- The AI chat page header: `Syna`, `New conversation`, `Onboarding`.
- Provider key setup (BYOK) — add / test / remove a key, pick default and fast
  model.
- Zero-AI state: entries hidden when no provider is configured.
