## Scope

Everything an administrator does: provision an instance, install and update
apps, manage roles and members, configure BYOK keys and understand backups.

## Screens this page will cover

- Settings — `User` (`Profile`, `Experience`), `Workspace` (`General`,
  `Data model`, `Layout`, `Members`, `Billing`, `MCP & APIs`, `Apps`,
  `Syna`), `Other` (`Admin Panel`, `Community`, `Support`, `Documentation`).
- Settings → `Workspace` → **Syna** — `Models`, `Usage`, `Audit` (keys, usage
  cap).
- Settings → `Roles` and permissions.
- App catalogue install / upgrade / uninstall and its data policy prompt.
- Archive `Storage usage` (workspace storage).
