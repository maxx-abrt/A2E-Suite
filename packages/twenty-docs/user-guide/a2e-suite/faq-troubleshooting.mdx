## Scope

One place for the questions that keep coming back, grouped by surface, with
the exact screen where the fix lives.

## Screens this page will cover

- **Bureau** — a document is not in `Tous les documents`; a task is not in
  `Mes tâches`; where `Modèles` documents go.
- **Agenda** — an event is missing from the calendar; a recurrence edit did
  not apply to the scope you expected; a reminder did not fire.
- **Bilan** — a fiche does not appear under `Fiches officielles`; a quote or
  invoice is missing from `Tous les devis` / `Toutes les factures`.
- **Syna** — no answer and no key configured; the `Connect a provider`
  prompt; usage limit reached (`Get more credits`).
- **Archive** — `Could not load Archive`; a file is in `Trash`; storage is
  full (`Storage usage`).
- **Admin** — an app failed to install; a member cannot see a record.
