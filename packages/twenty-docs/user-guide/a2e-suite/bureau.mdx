> **Version documented:** A2E Suite 0.2.1 · Twenty 2.39.0.
>
> This is the M12a skeleton. The walkthrough ships in **M12c**.
> Bureau has no standalone app definition today; it composes the existing
> Documents (`a2e-documents`), Projets (`a2e-projects`) and Discussions
> (`a2e-chat`) apps.

## Scope

The knowledge and delivery surface: write documents, run projects, track
tasks, discuss in channels, and open every record page.

## Screens this page will cover

Sidebar rows and views (labels are the shipped source labels):

- Documents — `Documents`, `Tous les documents`, `Modèles`.
- Projects — `Projets`, `Tous les projets`, `Tous les jalons`,
  `Toutes les étiquettes`.
- Tasks — `Mes tâches`, `Assignées à moi`, `Créées par moi`, `En retard`,
  `Tâches courantes`, `Tâches projet`, `Board tâches`, `Calendrier tâches`.
- Discussions — `Discussions`, `Tous les canaux`, `Tous les messages`,
  `Membres des canaux`.

Record pages:

- Document record page (document page layout, template `Modèles`).
- Project record page (project page layout) and task record page.

Command menu:

- `Bureau : créer un projet`, `Bureau : créer une tâche`,
  `Bureau : créer un document`, `Bureau : créer un canal`,
  `Bureau : dépendances`, `Bureau : sous-tâches`, `Bureau : chronomètre`,
  `Bureau : enregistrer comme document`, `Bureau : aller aux projets`,
  `Bureau : aller aux documents`, `Bureau : aller aux discussions`.

## Limits

Bureau co-editing is stale-write detection, not live OT.
