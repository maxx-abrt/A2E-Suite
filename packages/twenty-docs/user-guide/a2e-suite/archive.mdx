## Scope

Store and organise files: folders, upload, preview, trash and storage usage.

## Screens this page will cover

- The `Archive` sidebar row, linking to `/drive`.
- The `/drive` page — `New folder`, `Trash`, `Storage usage`, `Loading…`,
  `Could not load Archive`.
- Drive views — `Tous les dossiers`, `Tous les fichiers`.
- File preview and the file record page.

## Planned sections

1. Create a folder and upload a file.
2. Preview a file.
3. Move to `Trash` and restore or purge.
4. Read `Storage usage`.
5. Use a folder-structure template.
