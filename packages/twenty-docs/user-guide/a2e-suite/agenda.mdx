## Scope

See, create and edit events; understand recurrence and edit scopes; manage
reminders; and distinguish task deadlines from calendar events.

## Screens this page will cover

- The `/calendar` page and its view switcher (month / week / day /
  `Agenda`).
- The agenda list: `Agenda`, `No events in this range`, `All day`,
  `Untitled event`.
- Event create/edit panel, including recurrence and edit-scope choices.
- Reminders (`Reminder` settings on an event).
- Task deadlines shown on a calendar — the project `Calendrier tâches` view.
