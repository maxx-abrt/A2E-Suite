## Scope

Move one story across apps — meeting → notes → tasks → invoice — and follow
the same record everywhere.

## Screens this page will cover

Shipped today (per-pair relations):

- Document ↔ Project relation, task ↔ project, document ↔ task.
- Command menu `Bureau : dépendances` and `Bureau : sous-tâches`.

Planned (M11a):

- Universal **link picker** from any record.
- **Related** widget listing links and backlinks on record pages.
