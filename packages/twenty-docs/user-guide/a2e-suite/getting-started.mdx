## Scope

How a new user reaches a working A2E workspace: create the workspace, choose a
persona starting point (what installs, what is seeded, the first action) or
**Start from scratch**, then learn the shell (sidebar sections, reorder and
hide, `Cmd+K`, side panel vs full page, Home).

## Screens this page will cover

- Workspace onboarding / **Continue with Email** entry.
- Persona picker and the **Start from scratch** path (M13b).
- Sidebar sections, app rows and the navigation reorder/hide controls.
- Command menu, `Cmd+K`.
- **Home** / Today landing.
- Settings — `User` (`Profile`, `Experience`) and `Workspace` (`General`,
  `Data model`, `Layout`, `Members`).
