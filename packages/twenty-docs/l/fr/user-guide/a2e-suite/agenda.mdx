> Ceci est l'ébauche M12a. Le parcours est livré en **M12c**.
> L'Agenda est la page hôte `/calendar` ; pas encore de ligne dédiée dans la
> barre latérale (PLAN M7b/M7d).

## Périmètre

Voir, créer et modifier des événements ; comprendre la récurrence et les
portées d'édition ; gérer les rappels ; distinguer les échéances de tâches des
événements de calendrier.

## Écrans couverts par cette page

- La page `/calendar` et son sélecteur de vue (mois / semaine / jour /
  `Agenda`).
- La liste agenda : `Agenda`, `No events in this range`, `All day`,
  `Untitled event`.
- Panneau de création/édition d'événement, récurrence et portée d'édition.
- Rappels (`Reminder` sur un événement).
- Échéances de tâches sur un calendrier — vue projet `Calendrier tâches`.

## Sections prévues

1. Naviguer dans le calendrier et changer de vue.
2. Créer et modifier un événement.
3. Récurrence et dialogue de portée (cet événement / celui-ci et suivants /
   tous).
4. Rappels.
5. Échéances de tâches vs événements.
