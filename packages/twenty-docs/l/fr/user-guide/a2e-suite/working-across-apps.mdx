Faire voyager une histoire entre les apps — réunion → notes → tâches →
facture — et retrouver le même enregistrement partout.

- Relation Document ↔ Projet, tâche ↔ projet, document ↔ tâche.
- Menu de commandes `Bureau : dépendances` et `Bureau : sous-tâches`.

Prévus (M11a) :

- **Sélecteur de lien** universel depuis n'importe quel enregistrement.
- Widget **Related** listant liens et liens retour sur les pages
  d'enregistrement.
