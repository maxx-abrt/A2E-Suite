## Périmètre

Un seul endroit pour les questions qui reviennent, groupées par surface, avec
l'écran exact où se trouve le correctif.

## Écrans couverts par cette page

- **Bureau** — un document n'est pas dans `Tous les documents` ; une tâche
  n'est pas dans `Mes tâches` ; où vont les documents `Modèles`.
- **Agenda** — un événement manque au calendrier ; une édition de récurrence
  ne s'est pas appliquée à la portée attendue ; un rappel n'a pas eu lieu.
- **Bilan** — une fiche n'apparaît pas dans `Fiches officielles` ; un devis ou
  une facture manque dans `Tous les devis` / `Toutes les factures`.
- **Syna** — pas de réponse et aucune clé configurée ; l'invite
  `Connect a provider` ; plafond d'usage atteint (`Get more credits`).
- **Archive** — `Could not load Archive` ; un fichier est dans `Trash` ; le
  stockage est plein (`Storage usage`).
- **Admin** — une app n'a pas pu s'installer ; un membre ne voit pas un
  enregistrement.
