> arrive avec M10a (cœur serveur déjà fait).

## Périmètre

Configurer un fournisseur avec votre propre clé, poser des questions en
contexte et utiliser les actions IA par app — avec un état sans IA correct
quand aucune clé n'est configurée.

## Écrans couverts par cette page

- Réglages → **Syna** : onglets `Overview`, `Models`, `Skills`, `Tools`,
  `Usage`, `Audit` ; `New Skill`, `New Tool`, `Watch AI demo`.
- En-tête du chat IA : `Syna`, `New conversation`, `Onboarding`.
- Configuration de clé fournisseur (BYOK) — ajouter / tester / retirer une
  clé, choisir les modèles par défaut et rapide.
- État sans IA : entrées masquées quand aucun fournisseur n'est configuré.
