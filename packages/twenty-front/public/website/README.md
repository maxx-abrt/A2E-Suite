# Public site assets

These assets come from the local `packages/twenty-website` base. The native public site reuses its authored tokens, section primitives, beveled buttons, notched footer, typography and bridge illustration. Internal package names remain unchanged.

Fonts are self-hosted Latin subsets under SIL Open Font License 1.1; see `packages/twenty-website/src/fonts/README.md` for upstream sources. No remote font, booking, customer or community service is required by the public page.
